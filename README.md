### Примеры

Выгрузить проект demo в каталог проекта в подкаталог /.export, при вызове из каталога проекта:

`jeweltools export`

Выгрузить проект demo, находящийся в каталоге C:\demo в каталог C:\export\demo:

`jeweltools export -p C:\demo --ep C:\export\demo`

Выгрузить проект demo, находящийся в каталоге C:\demo в каталог C:\export\demo, используя рабочую область %LOCALAPPDATA%\1C\1cedtstart\projects\demo:

`jeweltools export -d %LOCALAPPDATA%\1C\1cedtstart\projects\demo -p C:\demo --ep C:\export\demo`

## v8storage

### Описание
Набор команд для работы с хранилищем конфигурации. Применяется к проекту, хранящемуся в репозитории git.

### `v8storage pull`
Подкоманда `pull`. Получает коммиты из хранилища конфигурации 1С. Вызывает утилиту gitsync, у которой должен быть включен плагин edtExport. Не имеет опций.

### Пример
`v8storage pull`

### `v8storage push`
Подкоманда `push`. Считывает изменения коммитов git и отправляет изменения в хранилище конфигурации 1С. Изменения определяются между HEAD коммитом и его предком.

# Установка

### Для тех у кого уже всё есть:
1. Скачайте пакет ospx со страницы релизов
2. Вызовите команду `opm install jewel-tools-<номер версии>.ospx` из каталога, где находится скачанный пакет

### Для остальных:
1. Удалите onescript, если он был установлен не через ovm
2. Установите ovm `https://github.com/oscript-library/ovm`
3. Установите onescript через ovm
4. Вызовите `opm install --all`
5. Теперь у вас всё есть

# Настройка

В каталоге `%LOCALAPPDATA%\ovm\current\lib\jewel-tools\templates` лежат файлы:
1. AUTHORS
2. VERSION
3. autumn-properties.json

AUTHORS и VERSION используются утилитой v8storage, требуются для gitsync при получении коммитов из хранилища.

`AUTHORS` - хранит список пользователей хранилища конфигурации, необходимо заполнить этот список по шаблону.

`VERSION` - хранит номер версии хранилища, которая успешно импортировалась в проект EDT. Если указана версия 0, тогда будут получены все версии из хранилища. Если требуется только последняя версия, тогда нужно указать последнюю версию в хранилище минус один. Пример: в хранилище последняя версия 101, чтобы затянуть в EDT эту версию нужно указать версию 100 в файле VERSION.

`autumn-properties.json` - хранит настройки консольного приложения jeweltools.

Эти файлы должны размещаться в корне каталога проекта EDT. Каталогом проекта является каталог, в корне которого находится файл `.project`.

## autumn-properties.json

Хранит ключи настроек консольного приложения jeweltools. Если ключ настройки отсутствует, значит эта настройка вообще не учитывается.

### logos

Настройки логирования, см. [Конфигурирование autumn-logos](https://autumn-library.github.io/autumn-logos/#конфигурирование). По умолчанию лог выводится в консоль.

### Gitsync

Настройки вспомогательной утилиты gitsync (https://github.com/oscript-library/gitsync). По умолчанию настроены опции:
- GITSYNC_VERBOSE - включено подробное логирование
- GITSYNC_DISABLE_AUTO_SRC - отключен автопоиск папки src
- GITSYNC_SORT_SUBORDINATE_OBJECTS - список подчиненных объектов, которые нужно сортировать. Требуется включить плагин sortProject, см. https://github.com/DmitryShehovtsev/sortproject

### ИсключениеПриОчисткеКаталогаПроекта

Список служебных файлов/каталогов, которые нужно сохранить при очистке каталога проекта в момент актуализации проекта при полной выгрузке (Full dump). По умолчанию добавлен файл настроек autumn-properties.json. (Восстановление AUTHORS и VERSION гарантирует gitsync).

### ВременныйКаталог

При необходимости здесь переопределяется каталог к временным файлам. Если ключ отсутствует, тогда используется папка Temp.

### Хранилище

Настройки подключения к хранилищу.
- Путь - Путь к каталогу хранилища
- Логин - Логин пользователя хранилища
- Пароль - Пароль пользователя хранилища

### БазаПодключеннаяКХранилищу

Настройки подключения к разработческой базе, подключенной к хранилищу. Удобно для сохранения доступа к хранилищу из конфигуратора или для случая выполнения коммита в хранилище из конфигуратора (возврата в конфигуратор). При отсутствии этой опции, для подключения к хранилищу будет использована временная файловая база и в дальнейшем подключиться к этому хранилищу под тем же пользователем из конфигуратора уже не получится, потребуется переподключение к хранилищу из конфигуратора, что может занимать довольно продолжительное время.

- Серверная
  - Используется - Булево
  - ИмяСервера - Строка
  - ИмяБазы - Строка

- Файловая
  - Используется - Булево
  - Путь - Строка

- Авторизация
  - Логин
  - Пароль

# Замечания

1. Рекомендуется включить следующие плагины gitsync:
- increment
- tool1CD
- disable-support
- edtExport
- sortProject

https://github.com/oscript-library/gitsync-plugins

https://github.com/oscript-library/gitsync#настройка-плагинов-синхронизации


2. jeweltools требует наличия файла autumn-properties.json в рабочем каталоге (cwd). Это недоработка, как и тот факт, что для запуска любой утилиты требуется инициализация всех желудей, что очевидно является избыточным, например для вызова export. Запланировано...
